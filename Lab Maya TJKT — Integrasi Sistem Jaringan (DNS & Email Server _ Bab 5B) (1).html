Teori Singkat: Integrasi DNS & Email Server (Bab 5B)

1. Peran DNS Server (BIND9) dalam Sistem Email

Layanan Email Server tidak dapat berdiri sendiri tanpa DNS (Domain Name System). Ketika seseorang mengirim email ke guru@smkn2.sch.id, komputer pengirim harus mengetahui alamat IP server yang menangani email domain tersebut melalui dua jenis record utama:

  • MX Record (Mail Exchanger): Menunjuk nama hostname Mail Server tujuan beserta nilai prioritas (contoh: @ IN MX 10 mail.smkn2.sch.id.).
  • A Record (Address): Menerjemahkan hostname Mail Server menjadi alamat IPv4 fisik (contoh: mail IN A 192.168.10.3).

2. Arsitektur Layanan Email Server (Postfix & Dovecot)

SMTP (Port 25)

Dijalankan oleh Postfix (MTA) untuk mengirim dan meneruskan email antar server maupun dari klien pengirim.

IMAP (Port 143)

Dijalankan oleh Dovecot (MDA). Menyinkronkan email dan menyimpan salinan pesan tetap berada di direktori Maildir server.

POP3 (Port 110)

Dijalankan oleh Dovecot (MDA). Mengunduh email ke perangkat klien lokal lalu menghapus salinan pesan di server.

Instruksi Praktikum Lab Maya (Bab 5B)

Langkah 1: Verifikasi Konfigurasi DNS Server (BIND9)

Periksa panel kiri tab DNS (BIND9). Pastikan terdapat record mail IN A 192.168.10.3 dan @ IN MX 10 mail.smkn2.sch.id.. Klik tombol Uji DNS Lookup (`dig` MX & A) di bagian atas kanvas tengah untuk melihat resolusi nama domain.

Langkah 2: Manajemen User & Protokol Mail Server

Buka tab Mail Server di kolom kiri. Tambahkan satu akun user baru (misalnya: tkj). Pastikan protokol Dovecot berada pada mode IMAP (TCP Port 143).

Langkah 3: Simulasi Pengiriman & Penerimaan Email (IMAP vs POP3)

Pada form Compose Email (Client PC-1), kirim email dari siswa@smkn2.sch.id menuju guru@smkn2.sch.id. Amati 5 tahapan paket pada kanvas serta log dialog SMTP & IMAP. Selanjutnya ubah protokol Dovecot menjadi POP3 (Port 110) dan kirim email kedua untuk mengamati perbedaan penyimpanan di server.

Langkah 4: Uji Troubleshooting Jaringan

Aktifkan salah satu gangguan pada bagian Simulasi Gangguan (misalnya: Hapus / Nonaktifkan MX Record atau Firewall Blokir Port 25), lalu coba kirim email kembali. Catat kode error yang muncul pada terminal untuk menjawab pertanyaan pada LKPD.
